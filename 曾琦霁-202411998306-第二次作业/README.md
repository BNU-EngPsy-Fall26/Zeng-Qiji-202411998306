# NORTHSTAR｜注意实验室

一个纯前端、可在本地运行的交互式注意实验网站。项目包含两个经典范式：W5 的多仪表监控与预测性注意引导，以及 W6 的视觉搜索与并行加工（Treisman & Gelade, 1980）。

## 2. 收数前的研究预测

### 实验一：多仪表监控与预测性注意引导

- **H1｜事后提示的作用：** 与无提示条件 A 相比，事后提示条件 B 的真实异常命中率预计更高，正确命中反应时预计更短。该预测检验异常发生时的显著提示能否改善发现与响应。
- **H2｜预测性提示的增益（改进预测）：** 与事后提示条件 B 相比，预测性提示条件 C 的正确命中反应时预计更短，命中率预计不低于 B。主要关注反应时差异，命中率作为补充指标。反应时以屏幕首次呈现越界状态为起点，而非提示出现时间。
- **H3｜预测错误的代价：** 在接近阈值后恢复、最终不越界的近失误试次中，C 条件预计出现更多预测提示，并可能有更高的虚报或提前响应比例。该差异不预设必然出现。

### 实验二：视觉搜索与并行加工

- **H1｜特征搜索与联合搜索的斜率差异：** 特征搜索（A）的反应时随搜索集大小增长应接近平坦；联合搜索（B）的反应时斜率应显著大于 0，且大于 A。正确率上，随集大小增加，B 的下降幅度预计大于 A。
- **H2｜预览的搜索增益（改进预测）：** 与联合搜索 B 相比，预览条件 C 的反应时斜率应更小，正确率不低于 B。依据 Watson 与 Humphreys（1997）的视觉标记研究，先呈现的旧项目会被抑制，使被试可优先选择新项目。
- **H3｜增益随集大小变化（探索性）：** 预览带来的斜率下降在较大集大小（16、32）上应比小集大小（4、8）更明显；目标缺失试次的斜率通常高于目标存在试次。该预测作为探索性分析报告。

### 预测的检验原则

主要比较、因变量与排除规则详见 `PRE_REGISTRATION.md`。结果无论支持、不支持或部分支持预测，都必须如实报告。课程最低样本量较小，条件差异与效应量只作为初步证据，不应夸大为稳定结论。

## 3. 实验一：多仪表监控与预测性注意引导（W5）

### 理论与原始研究

Senders（1964）研究多仪表监控中的视觉采样行为，经典任务涉及多个动态指针和阈值事件。SEEV 框架（Wickens 等）用于解释任务价值、期望、显著性与努力对注意分配的影响；Horrey 等（2006）将 SEEV 用于驾驶员视觉注意研究。本项目借鉴多仪表监控任务并以 SEEV 作为解释背景，不声称 Senders 提出了 SEEV，也不把按键反应等同于真实注视或视觉采样频率。

### 研究问题与条件

研究问题：系统依据仪表趋势提前提示，能否改善异常检测；预测错误是否带来额外虚报或注意转移？

| 条件          | 提示规则                                                        | 界面表现          |
| ----------- | ----------------------------------------------------------- | ------------- |
| A 无提示       | 被试自主监控，越界时无额外提示                                             | 表盘始终为常规配色     |
| B 事后提示      | 目标仪表实际越过阈值时提示                                               | 越界瞬间该表盘整体变红   |
| C 预测性提示（新增） | 依据目标指针最近约 520 ms 的趋势回归估计 TTC；估计 TTC ≤1500 ms 时提示，实际提前量逐试次记录 | 先变黄预警，真正越界后变红 |

提示完全由目标表盘颜色表达（盘面、指针、读数与卡片边框同步变色并脉冲），不出现文字横幅或状态文案；三个条件除颜色规则外界面一致。C 条件的近失误试次会先接近阈值、可能触发预测提示，随后减速反向、最终不越界，用于检验错误预测的代价。实际提前量随实时趋势变化，逐试次记录，不假定恒定为 1500 ms。

### 试次结构

- 每条件 16 个正式试次：12 个真实异常、4 个近失误；每个试次另有两次非目标仪表扰动。
- 真实异常按四个仪表各 3 次分配；每个仪表包含上/下方向与快/慢轨迹；全条件合计 6 次上越界、6 次下越界、6 次较快、6 次较慢。
- 阈值：空速 190–310 kt；高度 3600–6400 ft；横滚角 −18° 至 +18°；发动机温度 560–790 °C（课程模拟值）。
- 每个条件前有 2 次练习，不计入数据；正式试次共 48 次。
- A/B/C 使用同一套匹配刺激项目，仅条件内重新随机排序；条件顺序按匿名编号在六种排列中平衡。

### 因变量

命中率、漏报、虚报、提前响应、正确命中反应时、预测提示触发率、预测准确率与提前量。结果页额外比较快/慢轨迹下的命中率。目标信号微幅扰动与两档轨迹斜率为网页改编参数，不等同于 Senders 原研究的完整信号带宽操纵。

## 4. 实验二：视觉搜索与并行加工（W6）

### 理论与原始研究

Treisman 与 Gelade（1980）提出特征整合理论：当目标由单一特征（如颜色）定义时，搜索可以平行完成，反应时几乎不随项目数量增加；当目标需要绑定颜色与朝向等多个特征时，需要逐个将注意指向项目，反应时随项目数量线性上升。Wolfe（1994）的引导搜索模型进一步强调自下而上的显著性引导。本项目以搜索斜率（ms/项）作为并行加工与序列搜索的核心指标。

改进条件来自 Watson 与 Humphreys（1997）的视觉标记研究：先呈现一部分干扰项，再呈现其余项目与目标，被试可以抑制已看过的旧项目，从而加快对新项目的搜索。

### 条件

| 条件         | 干扰项构成       | 呈现方式                          |
| ---------- | ----------- | ----------------------------- |
| A 特征搜索     | 全部为绿色竖条     | 全部项目同时出现；目标 = 红色竖条（单一颜色特征）    |
| B 联合搜索     | 红色横条与绿色竖条混合 | 全部项目同时出现；目标 = 红色竖条（颜色 × 朝向绑定） |
| C 预览搜索（改进） | 与 B 相同      | 先呈现一半干扰项 1000 ms，再加入其余项目与目标   |

三个条件的目标始终是红色竖条；A/B/C 使用完全相同的空间布局，仅干扰项构成与呈现时序不同。

### 试次结构

- 搜索集大小：4、8、16、32 项；每个集大小 10 次（目标存在 5 次、目标缺失 5 次）。
- 每条件 40 个正式试次；条件前 2 次练习不计入数据；正式试次共 120 次。
- 每试次流程：中央注视十字 500 ms → 搜索画面（预览条件先显示旧项目 1000 ms）→ 作答 → 对错反馈 450 ms。
- 反应时限 6 秒，超时记为错误；反应时从完整搜索画面出现时开始计时（预览条件从新项目加入时开始）。
- 目标位置、项目位置由匿名编号与刺激编号确定，保证同一被试在三个条件下看到相同布局。

### 因变量与预设比较

- 正确率（全部试次）。
- 正确反应时中位数（按集大小分组，目标存在试次）。
- 搜索斜率：对每名被试在 4 个集大小上的正确 RT 中位数做线性回归，得到 ms/项；再对斜率做被试内比较。
- 主要比较：B−A（联合 vs 特征，检验范式是否成立）；C−B（预览 vs 联合，检验改进是否有效）。
- 同时报告目标缺失试次与各集大小的完整表格，不只报告有利的对比。

结果面板可读取浏览器本地记录，也可导入课程平台下载的 CSV 或 JSON：

- 实验一：三条件命中率、虚报率、正确命中 RT 中位数；C 条件预测覆盖率、预测准确率与平均提前量；快/慢轨迹的监控绩效；被试内差值与 Cohen's *d*<sub>z</sub>。

- 数据覆盖检查：至少 5 名其他被试，并检查每位被试的每个条件是否达到至少 10 条试次。

Cohen's *d*<sub>z</sub> 按被试内条件差值的均值除以差值标准差计算。样本较小时效应量只作描述性估计，不应仅凭显著性声称机制已被证实。

**与原论文比较：** 实验一可以比较多仪表监控中变化速度、提示条件与检测绩效的方向性关系，但未复现 Senders 的专业眼动设备与原始信号带宽范式。实验二可以比较特征搜索与联合搜索的斜率方向，以及预览是否降低斜率；本项目使用网页刺激、固定 1000 ms 预览和 4 档集大小，数值不应与 Treisman 与 Gelade（1980）或 Watson 与 Humphreys（1997）的原始效应量直接等同。另需注意：预览条件同时改变了“是否预览”和“新出现项目的数量”，因此 C 低于 B 的斜率既可能来自视觉标记，也可能部分来自需要检查的新项目更少；讨论时应明确这一混淆，不能只归因于抑制机制。

1. **B 是三个条件里最好的。** 命中率 89% 对 A 的 61%，虚报率 2.5% 对 10.0%，d′ 2.48 对 1.25，且判断标准 c 接近中性（−0.03），说明被试既没变保守也没变冒进，是真的看得更准了。
2. **C 在预注册口径下几乎等于 A。** d′ 1.30 对 1.25（*d*<sub>z</sub> = 0.03），但它的命中 RT 是三者最短（305 ms，比 B 快约 92 ms），提前响应率却最高（27.5%）。
3. **C 的方差极大**（d′ 标准差 2.08、命中率标准差 34.5）。这不是纯噪声，而是两种截然不同的策略混在一个条件里——见 8.2.3。

#### 7.2.3 C 条件到底发生了什么：提前响应与提示有效度

把 C 的异常试次拆开看，结论会变化：

- **C 条件 120 个真实异常试次中，漏报为 0。** 而 A 漏报 24 次、B 漏报 3 次。也就是说，**在 C 条件下没有一个人"没发现"异常**（120/120 都作了反应）。
- 但 C 有 33 次（27.5%）按键发生在越界显示**之前**，按预注册规则记为"提前响应"，不计命中。这才是 C 命中率只有 72.5% 的直接原因。
- 这 33 次提前响应并不都是乱按：
  - **21 次发生在黄灯亮起之后**，中位数只比越界点早 994 ms——正是被试顺着预测提示提前准备、提前按键。
  - 12 次发生在黄灯之前或黄灯未触发时，中位数早 4166 ms——这些是真正盲猜。
- 对照 A/B：A 的 23 次、B 的 10 次提前响应，中位数只比越界点早 **160 ms / 152 ms**，属于"看到越界了但手快了一帧"的边界抖动，性质完全不同。

再看**提示本身准不准**。C 条件共触发 145 次预测提示，其中 108 次后面真有异常，**提示有效度 = 74.5%**；而在 40 个"接近阈值后恢复"的近失误试次里，算法触发了 **37 次**假警报（92.5%）。提示平均提前量 2200 ms。

> 解释：C 条件展示的不是"预测提示无效"，而是**低有效度预警的代价**——算法在近失误试次上几乎必然误报（因为近失误本来就是逼近阈值后回撤），被试因此学会了"黄灯即按"，于是在真异常上提前按键（记为提前响应）、在近失误上按了不该按的键（虚报率 10% → 22.5%）。命中 RT 变短、虚报率上升、判断标准几乎不偏移，这三者同时出现，是典型的"更敢报"而非"看得更准"。这与自动化告警研究中"低可靠度告警导致信任下降与过度反应"的模式一致（Parasuraman & Riley, 1997）。

#### 7.2.4 稳健性检验

两种扰动：① 把"越界前 600 ms 内"的提前按键改判为检出（承认边界抖动与顺着黄灯的即时反应）；② 剔除总体正确率低于 50% 随机水平的 P03、P05。

| 口径                       | A：d′ / c     | B：d′ / c     | C：d′ / c         | C − A 的 d′ 差                                  | C − B 的 d′ 差 |
| ------------------------ | ------------ | ------------ | ---------------- | --------------------------------------------- | ------------ |
| **预注册严格 · N = 10（主要分析）** | 1.25 / +0.35 | 2.48 / −0.03 | 1.30 / +0.04     | +0.05                                         | −1.18        |
| 容差 600 ms · N = 10       | 1.68 / +0.14 | 2.78 / −0.18 | 1.64 / −0.13     | −0.04                                         | −1.14        |
| 预注册严格 · N = 8            | 1.39 / +0.21 | 2.62 / −0.03 | **2.27** / +0.05 | **+0.88**                                     | −0.35        |
| 容差 600 ms · N = 8        | 1.85 / −0.02 | 2.98 / −0.21 | **2.67** / −0.15 | **+0.82**（*d*<sub>z</sub> = 2.25, *p* < .001） | −0.31        |

结论的稳定性分三层：

- **A 最差、B 最好**：四种口径下结论完全一致，稳健。
- **C 是否优于 A**：完全取决于是否保留那两名低于随机水平的被试。保留时 C ≈ A（+0.05 / −0.04）；剔除后 C 明显优于 A（+0.82 ~ +0.88 个 d′，*d*<sub>z</sub> > 2）。也就是说，C 的均值被少数"连续抢答"的被试拉平了，而不是被所有人一致地拖低。
- **C 是否优于 B**：四种口径下答案都是"没有"（C − B 的 d′ 差在 −0.31 ~ −1.18 之间）。这一条结论稳健。

#### 7.3.1 集大小函数

### 7.4 与原论文的对照

**实验二**

- Treisman 与 Gelade（1980）报告：特征搜索的斜率接近 0（通常 0–5 ms/项），联合搜索约 20–40 ms/项且呈明显线性。本实验 A 的 0.5–3.5 ms/项、B 的 20.3 ms/项落在原研究的区间内，**范式有效性得到确认**；B 的 R² = .975 也说明集大小几乎单独解释了反应时变异，与"逐项注意检查"的序列假设一致。
- Watson 与 Humphreys（1997）的视觉标记研究：先呈现旧项目可使新项目的搜索斜率显著下降。本实验 C 的斜率（合并拟合 9.7 ms/项）约为 B 的一半，方向与原研究一致，但**幅度不能直接等同于视觉标记效应**：C 同时改变了"是否预览"和"新加入项目数量"（32 项时只有 16 个是新的），斜率下降有一部分必然来自需要检查的项目更少，而不是来自对旧项目的主动抑制。要真正分离这两种解释，需要加一个"旧项目数量相同但不做视觉标记"的控制条件。
- 与 Wolfe（1994）引导搜索的对照：A 的平坦曲线与 B 的线性曲线正是"单一特征可由显著性地图并行引导、特征绑定必须依赖注意"的分界，本实验在该分界上给出了清晰的组内证据。

**实验一**

- Senders（1964）的多仪表监控研究以眼动采样率为核心指标。本研究没有眼动设备，**不能**比较采样频率或注视分配，只能比较"阈值事件检出"这一行为层面的结果。方向性一致：仪表越多、信号越难分辨，检出越差（A 条件命中率仅 61% 即为基线）。
- SEEV 框架预测：提高某仪表的期望（E）与显著性（S）会把注意拉向该仪表。B/C 通过颜色变化同时提高了目标仪表的 S 与 E，命中率随之上升，方向符合 SEEV。但 SEEV 不预测"错误预警的代价"，C 的虚报上升需要借助告警信任与自动化使用的研究来解释（Parasuraman & Riley, 1997）：当告警有效度只有 74.5%、近失误试次 92.5% 误报时，使用者要么忽视、要么过度反应，本批数据表现为后者。
- 与原研究最大的差异在于**任务与刺激的量级**：网页仪表、4 个仪表、48 个试次、2 档轨迹速度，与 Senders 的连续控制任务不可比。因此这里只能说"提示条件的差异方向与文献一致"，不能说"复现了 Senders 的结论"。

### 7.5 限制

1. **样本量与统计功效。** 10 人、被试内 40 试次/条件，个体斜率建立在每格 3–9 个正确试次的中位数上，噪声很大（B 的人均斜率从 −8.4 到 +34.4）。C − B 的显著性在两种口径间翻转，说明这条结论目前的证据强度不足。
2. **d′ 存在天花板。** 每条件只有 12 个真异常、4 个近失误，0.5 校正后 d′ 上限为 3.05；**B 条件有 5/10 人达到该上限**（A、C 均无人达到）。因此 B 的 d′ 被部分截断，B 与 A、C 的真实差距应比 2.48 更大——这是低估而非高估。
3. **"提前响应"规则与 C 条件的设计相互冲突。** 预注册规定越界显示前的按键不计命中，这一规则在 A/B 下只影响边界抖动（中位提前 152–160 ms），但在 C 下会把"顺着黄灯提前按键"整批判为错误（27.5%）。这既是测量问题也是设计问题：如果改进条件是"让人更早预判"，就不该用"必须在越界后按键"作为唯一正确标准。8.2.4 的重编码是事后决定，只能作为稳健性参考，不能替代预注册分析。
4. **C 的提示算法在近失误试次上几乎必然误报。** 近失误试次本来就是"逼近阈值后回撤"，而 TTC ≤ 1500 ms 的触发条件恰好在这种轨迹上成立，于是 40 个近失误试次触发了 37 次假警报，提示有效度仅 74.5%。所以 C 实际上是"高误报率预警"而非"高有效度预警"，它的绩效下降不能直接推广为"所有预测性提示都无效"。
5. **条件顺序未完全平衡。** 10 人只覆盖了六种排列中的 5 种，个别排列缺失；若存在顺序或练习效应，可能对特定条件的均值有偏。
6. **无眼动数据。** SEEV 在本研究中只以"命中份额"作为行为代理，不能等同于注视比例或采样频率；图 2 检验的是"事件率份额能否解释实测分配"，不是完整的 SEEV 权重拟合。
7. **预览条件的混淆。** C 同时改变"是否预览"与"新项目数量"，斜率下降无法单独归因于视觉标记的抑制机制（见 8.4）。
8. **两名被试低于随机水平。** P03、P05 在实验一以连续抢答为主（正确率 46%、44%）。保留时 C ≈ A，剔除后 C 明显优于 A——这说明 C 的结论对少数被试的策略高度敏感，也说明"是否报告并剔除这类被试"必须事先规定，而不是事后选择。

### 7.6 结论

**实验一。** 事后提示（B）是三个条件中最有效的：相对无提示，命中率提高 28 个百分点、d′ 提高 1.23、判断标准不变，属于"看得更准"而非"更敢报"。预测性提示（C）没有超过 B，但原因不是"预测没用"：在 C 条件下 120 个真异常**零漏报**、命中反应时最短（305 ms）、提前响应率最高（27.5%），被试确实利用了黄灯；问题在于这些提前按键按预注册的计时规则不算命中，以及提示本身有效度只有 74.5%（近失误试次 92.5% 误报）导致虚报率翻倍。剔除两名低于随机水平的被试后，C 的 d′ 从 1.30 升到 2.27，明显高于 A（1.39），仍低于 B（2.62）。因此更准确的表述是：**预测性提示能加快检测并消除漏报，但在低提示有效度下会把收益换成虚报；要让"预测"真正优于"事后提示"，先要把告警有效度提上去。**

**实验二。** 特征搜索的集大小函数近乎水平（0.5 ms/项，R² = .049），联合搜索呈清晰线性上升（20.3 ms/项，R² = .975），两者的被试内差异在两种口径下都显著（*d*<sub>z</sub> = 0.78 ~ 1.87），支持特征整合理论的平行—序列二分。预览条件把斜率压到 9.7 ms/项（约为联合搜索的一半），方向与 Watson 与 Humphreys（1997）的视觉标记效应一致，且正确率没有下降；但该效应对口径敏感（预注册口径 *p* = .169，合并口径 *p* = .032），且预览同时减少了新项目数量，无法单独归因于主动抑制。**结论是"预览有帮助、方向可信、幅度待定"。**
